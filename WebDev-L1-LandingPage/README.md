# MOTIF — Artisan Mechanical Keyboards ⌨️✨

> **Oasis Infobyte Internship (OIBSIP) — Web Development and Designing**  
> **Level 1 — Task 1: Landing Page**

A modern, responsive, and visually refined landing page built for **MOTIF**, a fictional boutique brand specializing in precision-machined, artisan mechanical keyboards.

---

## 🌟 Live Demo & Preview

- **Local Preview:** `http://localhost:3000/`
- **Build Tool:** Powered by [Vite](https://vitejs.dev/)

---

## 🚀 Features

- **🎨 Modern Aesthetic Design**: Styled with a curated color palette (deep teal `#0e3b39`, coral accents `#e8613c`, warm paper `#fbfaf6`), clean typography with Google Fonts (*Space Grotesk* & *Inter*), and subtle transitions.
- **📱 Fully Responsive**: Fluid layouts that adapt gracefully across mobile, tablet, and desktop screens using modern CSS Flexbox and Grid.
- **⚡ Fast & Lightweight**: Zero runtime bloat, semantic HTML5, pure CSS variables, and fast bundling with Vite.
- **🧭 Sticky Navigation**: Sleek top navbar with smooth internal jump links and a quick pre-order CTA.
- **✨ Hero Section**: Catchy value proposition, live build statistics, dual action buttons, and high-quality product imagery.
- **🛠️ Feature Showcase**: Highlights core product benefits (Gasket-mounted feel, Tuned acoustics, Hot-swap architecture).
- **🔬 Craft & Storytelling Section**: In-depth look at materials, CNC machining, hand-lubed switches, and quality assurance.
- **💬 Social Proof & Reviews**: Testimonials from software engineers, product designers, and writers.
- **🎯 Conversion-Focused CTA**: Clear pre-order reservation banner.
- **🔗 Comprehensive Footer**: Navigation links, legal disclaimers, and contact details.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** Vanilla CSS3 (Custom Properties, Flexbox, CSS Grid, Responsive Media Queries)
- **Typography:** [Google Fonts](https://fonts.google.com/) (*Space Grotesk* & *Inter*)
- **Tooling / Dev Server:** [Vite](https://vitejs.dev/)

## 💻 Getting Started

Follow these steps to run the project locally on your machine:

### 1. Clone the Repository

```bash
git clone https://github.com/koushick007/OIBSIP-WebDev-L1-LandingPage.git
cd OIBSIP-WebDev-L1-LandingPage
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

Open your browser and visit: `http://localhost:3000/`

### 4. Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
