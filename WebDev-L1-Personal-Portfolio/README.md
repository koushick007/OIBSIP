# Koushick D — Personal Portfolio 🚀✨

**Oasis Infobyte Internship (OIBSIP) — Web Development & Designing**  
**Level 1 — Task 2: Personal Portfolio**

A modern, responsive, and visually refined personal portfolio website crafted for **Koushick D**, an aspiring Gen AI Engineer & Python Developer. Built with Next.js, React, Tailwind CSS / Vanilla CSS design tokens, and smooth micro-interactions.

---

## 🌟 Live Demo & Preview
- **Local Preview:** [http://localhost:3000/](http://localhost:3000/)
- **Framework & Tooling:** Powered by [Next.js](https://nextjs.org/) & [React](https://react.dev/)

---

## 🚀 Features

- 🎨 **Editorial Aesthetic & Modern Design:** Dark-themed minimalist aesthetic (`#11110f`), sophisticated typography pairing (`DM Serif Display`, `DM Sans`, and `DM Mono`), subtle borders, and smooth hover micro-animations.
- 📱 **Fully Responsive Layout:** Optimized for all screen resolutions (mobile, tablet, desktop) with a mobile navigation drawer and dynamic CSS grid/flexbox layouts.
- ⚡ **High Performance & Fast Loading:** Server-rendered and client-hydrated with Next.js App Router for optimal page speed and SEO performance.
- 🧭 **Intuitive Header Navigation:** Sticky branding (`KD.`), quick jump links to sections (About, Skills, Projects, Contact), and mobile drawer menu.
- ✨ **Hero Section:** Engaging headline with emphasis, availability status badge (`Available for opportunities`), quick call-to-action buttons, and subtle scroll cue.
- 👤 **About Me:** Highlights academic background (ECE at S.A. Engineering College), passion for Generative AI, RAG pipelines, AI agents, and workflow automations.
- 🛠️ **Interactive Toolkit / Skills Grid:** Curated tech stack display categorized by AI, Python, web frameworks, and developer tools with highlighted featured pills.
- 💼 **Featured Projects Showcase:** Clean project cards highlighting project index numbers, titles, concise problem/solution descriptions, tech stack tags, and direct GitHub links.
- 🎓 **Education & Certifications:** Structured timeline covering Bachelor of Engineering degree and professional technical certifications.
- 📬 **Interactive Contact & Quick-Copy:** One-click copy email button with instant feedback tooltip, direct links to LinkedIn & GitHub, and phone contact.

## 💻 Getting Started

Follow these steps to run the project locally on your machine:

### 1. Clone the Repository
```bash
git clone https://github.com/koushick007/OIBSIP.git
cd OIBSIP/WebDev-L1-Personal-Portfolio
```

### 2. Install Dependencies
```bash
npm install
# or
pnpm install
```

### 3. Run Development Server
```bash
npm run dev
# or
pnpm dev
```
Open your browser and visit: `http://localhost:3000/`

### 4. Build for Production
```bash
npm run build
npm run start
```
